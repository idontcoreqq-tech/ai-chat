# ИИ-чат (виджет в стиле Jivo)

Демо SPA на React + Vite: плавающий виджет чата с мок-ответами ИИ-агента.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

## Сборка

```bash
npm run build
npm run preview
```

## Структура

- `src/components/` — виджет, сообщения, ввод
- `src/data/mocks.js` — профиль агента и шаблоны ответов
- `src/services/chatApi.js` — слой отправки (`USE_MOCK = true`); позже замените на `fetch` к API

## Тема

Переключатель светлой/тёмной темы в шапке виджета. Выбор сохраняется в `localStorage`.

## Подсказки для теста

Напишите в чат про **доставку**, **оплату**, **возврат** или **номер заказа** — ответ подберётся по ключевым словам.
